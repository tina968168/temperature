# 温度 · Temperature

一件关于"冷门"的小作品。

语言模型说话的时候有一个参数叫**温度**：温度低，它只挑最可能的词，稳妥、正、无聊；温度高，它才敢挑那些不太可能的词。这件作品把这个旋钮交给你。

## 怎么玩

- 一个词一个词地写三句话。每一步都会给你几个候选词，标着各自的概率。你来挑，或者让小橘抽签。
- 选中的词从天上掉下来，小橘把它推进句子里。没选中的词也会掉下来，越堆越多。
- 挑到冷门的词（概率低于 10%），世界会变异：重力反转、地板变成海、月亮掉下来……
- 右上角的旋钮随时能拧。温度越高，画面越花，写完一句时的换场方式也越离谱。
- 小橘可以抓起来扔。扔狠了会晕。
- 三句写完是一首诗，会算出它有多冷门。

## 怎么打开

直接用浏览器打开 `index.html` 就行（需要联网加载字体和物理引擎）。
放到 GitHub Pages 上，就有一个谁都能玩的网址。
